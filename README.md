# Deutsch — CEFR Course & Tutor

Mobile-first long-term German learning PWA.

## v1 foundation
- CEFR A1→C2 architecture
- A1.1 ten-unit roadmap
- orientation placement assessment
- interactive Unit 1
- local progress/error tracking
- offline service worker
- course data separated from app code

Course content is original and organized around CEFR-style communicative outcomes. This is not an official Goethe-Institut product or CEFR examination.

For GitHub Pages, publish the `main` branch from the repository root.
